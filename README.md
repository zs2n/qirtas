# قرطاس

موقع استوديو قرطاس: صفحة واحدة، عربي وإنجليزي، فاتح وداكن. بلا إطار عمل وبلا خطوة بناء.

المباشر: https://zs2n.github.io/qirtas/

## تعديل المحتوى
كل المحتوى في الكائن `SITE` أعلى السكربت داخل `index.html`، وفوقه تعليق يشرح الطريقة.

- **لعبة جديدة:** أضف سطرًا في `SITE.games` (`status: "live"` مع `url`، أو `"soon"` بلا رابط).
- **خبر جديد:** أضف سطرًا في `SITE.posts` بالعنوان والتاريخ (`2026-11-23`) والنص بالعربية والإنجليزية.
- **إنستقرام:** ضع المعرّف في `SITE.instagram` فيظهر الزر. `null` يعرض «حساباتنا قريبًا».

## الشعار
الملفات في `assets/` هي الشعار الرسمي من نظام تصميم قرطاس. لا تعدّلها ولا تعِد رسمها.

## تجربة محلية
```bash
python3 -m http.server
```
